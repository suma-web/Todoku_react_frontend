# Frontendテスト方針と結果

## 方針

利用者に直接影響する認証、Role別画面制御、添付ファイル制限を最初の重点対象にしています。Vitest、jsdom、Testing Libraryを使用し、ブラウザ操作に近い形で表示と遷移を検証します。

## 重点テスト

| 対象 | 検証内容 | 防ぎたい問題 |
| --- | --- | --- |
| ログインAPI | Cookie付きリクエストと401エラー変換 | ログイン不能・誤ったエラー表示 |
| Role別ルート | admin許可、student拒否、未認証時ログイン遷移 | 管理画面の誤表示 |
| 添付形式 | PDF・JPEG・PNG・WebPのみ許可 | 未対応ファイル選択 |
| 添付件数 | 5件まで許可し6件目を拒否 | API制限との差異 |
| 1ファイル容量 | 10MB超過を拒否 | 過大ファイル送信 |
| 合計容量 | 25MB超過を拒否 | 複数ファイルによる制限超過 |

画面上の制御はセキュリティ境界ではないため、実際の認可はBackendでも別途テストしています。

## 実行方法

```bash
npm run test:coverage
npm run lint
npm run build
npm audit --omit=dev
```
